### `Carlos Fuso`

Sou desenvolvedor de software, com foco na criação de sistemas desktop para automatizar processos e facilitar a gestão de negócios.
Trabalho principalmente com Python, utilizando CustomTkinter para desenvolver interfaces modernas e SQLite para gerenciamento de bancos de dados.
Também utilizo ferramentas como Git, GitHub, PyInstaller e Inno Setup para controle de versões, criação de executáveis e instaladores para Windows.
Meu objetivo é desenvolver soluções práticas, intuitivas e eficientes, sempre buscando melhorar a experiência do usuário e otimizar tarefas do dia a dia.
Projeto em destaque: SCL Desktop — Sistema de Controle Lojista, desenvolvido para gerenciamento de vendas, funcionários, caixa, garantias e relatórios financeiros.
